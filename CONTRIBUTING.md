# Contributing to WebForge AI

Thanks for helping build WebForge AI.

## Development Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes with clear commit messages.
4. Run checks before opening a PR:

```bash
npm run lint
npm run build
```

5. Open a pull request with:
   - Problem summary
   - Proposed solution
   - Screenshots or short demo notes for UI changes

## Contribution Guidelines

- Keep architecture modular and provider-agnostic.
- Prefer small, testable changes.
- Avoid introducing breaking API changes without discussion.
- Update docs when behavior changes.

## Areas Open for Contribution

- AI provider integrations (OpenAI, Gemini, Ollama)
- Better code export formats
- Prompt templates and quality improvements
- Accessibility and UX enhancements
- Automated tests
